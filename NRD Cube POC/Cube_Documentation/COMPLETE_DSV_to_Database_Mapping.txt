ARCHITECTURE OVERVIEW:
--------------------------------------------------------------------------------
The Agent Performance MDM cube uses a three-layer architecture:

1. CUBE LAYER: Dimension and Measure Group Names (user-facing)
   Example: "Calls" measure group, "Fiscal Calendar" dimension

2. DSV LAYER: Data Source View Object Names (logical abstraction)
   Example: nq_Calls, nq_Fiscal_Calendar
   These are referenced in cube bindings via <TableID> tags

3. DATABASE LAYER: Physical SQL Server Tables/Views
   Example: FACT_MDM_CALLS_V, DIM_MDM_FISCAL_CAL_V
   These are the actual database objects to be migrated

This document maps Layer 2 (DSV) to Layer 3 (Database).
