# UDX Hackathon: Natural Language to SQL (NL2SQL) Assistant

## 🎢 Executive Summary

This hackathon project empowers Comcast UDX technical teams to build an **Advanced Agentic AI Business Intelligence Platform** using Snowflake's Cortex AI and cutting-edge agent capabilities. Participants will create sophisticated conversational interfaces that democratize data access, enabling business users to query both structured data and unstructured business documents using natural language, with intelligent agent orchestration providing comprehensive insights.

## 🎯 Project Goals

### **Primary Objectives**
- **Data Democratization**: Enable non-technical users to access insights independently
- **AI Skill Development**: Train teams on conversational AI and NL2SQL technologies
- **Business Intelligence Revolution**: Transform how UDX teams interact with data
- **Enterprise Integration**: Build production-ready solutions with governance and security

### **Learning Outcomes**
By completion, participants will be able to:
- Design and implement AI-powered natural language interfaces with agent orchestration
- Create context-aware conversational analytics experiences with multi-modal data integration
- Integrate NL2SQL capabilities with collaboration platforms (Slack/Teams) using agent enhancement
- Build secure, governed self-service analytics solutions with Snowflake Intelligence
- Develop business-friendly data access patterns combining structured and unstructured data
- **NEW**: Configure and deploy Snowflake Agents for intelligent workflow orchestration
- **NEW**: Implement Cortex Search for comprehensive business document integration
- **NEW**: Enable no-code access through Snowflake Intelligence portal (ai.snowflake.com)

## 🏗️ Technical Architecture

### **Technology Stack**
- **Platform**: Snowflake Cloud Data Platform with Cortex AI
- **AI Engine**: Advanced LLMs (llama3-8b, mixtral-8x7b, llama3-70b)
- **Languages**: SQL, stored procedures, JSON for configuration
- **Integration**: RESTful APIs, Slack/Teams SDK, mobile frameworks
- **Security**: Role-based access, audit logging, query governance

### **Core Components**
1. **Natural Language Processing**: Intent recognition and business context integration
2. **SQL Generation Engine**: Context-aware query translation and optimization
3. **Conversational Manager**: Multi-turn dialogue and context memory
4. **Platform Integration**: Slack/Teams bots and mobile interfaces
5. **Governance Framework**: Security, compliance, and resource management

## 📊 Dataset Overview

### **Business Analytics Data**
The project includes comprehensive UDX theme park business data optimized for analytics:

| Dataset | Records | Business Focus | Example Queries |
|---------|---------|----------------|-----------------|
| **CUSTOMERS** | 50,000 | Guest analytics and segmentation | *"Who are our most valuable customers?"* |
| **SALES_TRANSACTIONS** | 500,000 | Revenue and purchase behavior | *"What's our revenue trend this quarter?"* |

## 🎓 Hackathon Structure

### **Progressive Learning Path**
The hackathon follows a 9-lab progression from basic setup to advanced agentic AI platform:

#### **Labs 01-02: Foundation Building**
- **Lab 01**: Environment setup with business analytics data
- **Lab 02**: Basic natural language to SQL translation

#### **Lab 03: Advanced Features**
- **Lab 03**: Advanced query patterns, business logic, and conversational AI

#### **Lab 04: Complete NL2SQL Solution**
- **Lab 04**: Final challenge - production-ready traditional NL2SQL assistant

#### **🚀 Lab 05: Advanced Agentic AI (NEW)**
- **Lab 05**: Snowflake Agents & Intelligence integration with multi-modal orchestration

### **Learning Methodology**
- **Business-First Approach**: All exercises use realistic business scenarios
- **Hands-On Implementation**: Practical coding with immediate results
- **Progressive Complexity**: Skills build from simple to advanced AI integration and agent orchestration
- **Real-World Integration**: Focus on platforms teams actually use, enhanced with agentic capabilities
- **🚀 NEW - Agent-Native Development**: Learn to think in terms of multi-tool workflows and intelligent orchestration
