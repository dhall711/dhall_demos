# UDX Data Quality Project: GenAI-Powered Data Quality & Anomaly Detection Assistant

## 🎢 Welcome to the Comcast UDX Data Quality Project!

This hands-on project teaches technical teams how to leverage Snowflake's Cortex AI and LLM capabilities to build an autonomous data quality and anomaly detection system for theme park operations.

## 🎯 Learning Objectives

By the end of this project, participants will be able to:
- Implement Snowflake Cortex AI functions for data analysis
- Build automated data quality monitoring systems
- Create GenAI-powered anomaly detection workflows
- Generate natural language insights from data patterns
- Develop autonomous data cleansing recommendations

## 🏗️ Project Structure

```
UDX-Data-Quality-Project/
├── 01-setup/                    # Environment setup and data loading
├── 02-data-exploration/         # Understanding the theme park datasets
├── 03-basic-quality-checks/     # Traditional SQL-based quality checks
├── 04-cortex-integration/       # Introduction to Snowflake Cortex AI
├── 05-anomaly-detection/        # AI-powered anomaly detection
├── 06-nlp-insights/            # Natural language data summaries
├── 07-automated-recommendations/# GenAI-powered fix suggestions
├── 08-final-challenge/         # Build complete solution
└── sample-data/                # Theme park operational datasets
```

## 🎡 Business Context: UDX Theme Parks

Our datasets represent real-world theme park operations:
- **Guest Experience**: Ticket sales, ride satisfaction, wait times
- **Operations**: Ride performance, maintenance, weather impact
- **Revenue**: Merchandise, food sales, seasonal trends
- **Staff**: Scheduling, performance metrics

## 🧠 GenAI Capabilities Demonstrated

1. **Automated Pattern Recognition**: AI identifies unusual trends in guest behavior
2. **Natural Language Insights**: Convert complex data patterns into business language
3. **Predictive Quality Monitoring**: Forecast potential data quality issues
4. **Intelligent Recommendations**: AI suggests specific fixes for data problems
5. **Schema Evolution Detection**: Monitor and adapt to changing data structures

## 🚀 Getting Started

### Prerequisites
- Snowflake account with Cortex AI enabled
- Basic SQL knowledge
- Understanding of data quality concepts

### Quick Start
1. Run the setup scripts in `01-setup/`
2. Load sample data using `sample-data/load_all_data.sql`
3. Follow lab exercises sequentially (01 → 08)
4. Each lab builds on the previous one

### Lab Exercise Structure
Each lab contains:
- **README.md**: Learning objectives and concepts
- **setup.sql**: Required database objects
- **exercises.sql**: Hands-on challenges
- **solutions.sql**: Complete implementations
- **bonus-challenges.sql**: Advanced extensions

## 🏆 Final Challenge

Build a complete GenAI Data Quality Assistant that:
- Monitors all UDX datasets automatically
- Detects and classifies data quality issues
- Provides natural language summaries for business users
- Suggests and implements automated fixes
- Learns from historical patterns to improve accuracy
